## Description

Produces the synthetic sample files used for demonstration, automated tests and E2E: one sample CSV relative to the go-live date that exercises every rule, plus supporting files for whole-file refusals and window variants.

## Scope Detail

- Sample CSV generator relative to a supplied go-live date using seeded room names and seeded fictional people's emails
- One row for each rejection reason, one exact duplicate, one formula-leading cell, valid rows across five working days
- Wrong-header, oversized, weekend go-live and valid-only variants
- Usage note

## Technical Approach

A small generator (script or command) driven by one column definition so a change to ADR-0011 changes one place; output written to a local samples folder.

## Stories

---

### S-09.06.01: Generate the sample CSV relative to the go-live date

**Estimated Hours:** TBD

As a Software Engineer, I want a sample CSV generator so that the import can be demonstrated and tested with realistic content.

_Acceptance criteria:_

- [ ] The generator produces a `room,person_email,date,start,end,attendees` file for a supplied go-live date, with valid rows spread across the five working days using the seeded rooms and people.
- [ ] It contains one row for each rejection reason: unknown room, inactive Old Room, unknown person, outside window, weekend date, off grid, outside office hours, too short, too long, capacity exceeded, overlap with another row, beyond the third booking for a person, and in the past.
- [ ] It also contains one exact duplicate row and one cell that begins with a formula character.

_Notes:_ arch v1.2, Import Flow (POC data and sample file); NFR-004 volume generators are in F-10.02.
