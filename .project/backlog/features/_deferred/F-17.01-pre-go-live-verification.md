## Description

The checks required before the hosted pilot handles real data: security re-assessment against the hosted design, backup restore rehearsal, hosted performance and E2E, and gate and HTTPS verification on production.

## Scope Detail

- Security assessment re-run against the hosted design (SEC-01, SEC-05, SEC-12 re-activated)
- Backup restore rehearsal
- Full E2E, performance and security baseline on the hosted environment
- Gate reachability, HTTPS-only and uptime checks on production

## Technical Approach

Manual and pipeline-supported verification against the pre-go-live stage in the test strategy target state.

## Stories

---

### S-17.01.01: Re-run the security assessment against the hosted design

**Estimated Hours:** TBD

As a Program Architect, I want the security assessment re-run so that the hosted findings are current before real data is loaded.

_Acceptance criteria:_

- [ ] The assessment is re-issued for the hosted design with SEC-01, SEC-05 and SEC-12 active.
- [ ] No unresolved High or Critical finding remains; any triggers a `create-adr` decision.
- [ ] Deferred items (SQL firewall, TLS, headers, Key Vault, endpoint protection) are reviewed.

_Notes:_ Security assessment ADR Triggers section.

---

### S-17.01.02: Rehearse backup restore

**Estimated Hours:** TBD

As a Software Engineer, I want a restore rehearsal so that RPO 24 hours and RTO one business day are proven.

_Acceptance criteria:_

- [ ] A point-in-time restore of the database is performed and the application runs against it.
- [ ] The elapsed time is recorded against RTO one business day.
- [ ] The runbook is corrected from what was learned.

_Notes:_ NFR-008.

---

### S-17.01.03: Verify hosted performance and security baselines

**Estimated Hours:** TBD

As a QA Engineer, I want hosted results for the performance and security NFRs so that the pilot's targets are demonstrated on Azure.

_Acceptance criteria:_

- [ ] Page response p95 is under 2 seconds and a 500-row import completes in under 1 minute on the hosted test environment.
- [ ] The ZAP baseline shows no unresolved medium or higher finding.
- [ ] Results are recorded as the hosted baseline.

_Notes:_ NFR-003, NFR-004.

---

### S-17.01.04: Verify the full journey set and production gate

**Estimated Hours:** TBD

As a QA Engineer, I want full E2E and production checks so that the production release is safe.

_Acceptance criteria:_

- [ ] Full E2E (E2E-001 to E2E-014) passes on the hosted test environment through the gate.
- [ ] On production, unauthenticated requests redirect to sign-in, HTTP redirects to HTTPS and the deployment console is not anonymously reachable.
- [ ] The uptime probe is green during office hours.

_Notes:_ NFR-007, NFR-009, NFR-011.
