## Description

Creates the test and production Azure environments as code in the agreed EU region: App Service (Linux, Basic B1, one instance, Always On), Azure SQL Database at the smallest passing tier, HTTPS-only transport and managed identity to the database.

## Scope Detail

- Confirmation of subscription, region, SKUs and policy with client IT
- Bicep for test and production resource groups
- App Service configuration: HTTPS only, TLS 1.2 minimum, HSTS, Always On, settings and secrets
- Managed identity with a least-privilege database role; data protection key ring persistence; database firewall restriction

## Technical Approach

Bicep modules per resource, parameters per environment, deployed from the pipeline (E-15) or manually for the first environment.

### S-12.01.02: Define the environments in Bicep

**Estimated Hours:** TBD

As a Software Engineer, I want test and production defined as code so that environments can be recreated.

_Acceptance criteria:_

- [ ] One deployment creates the resource group contents for either environment; the test environment can be stopped outside working hours.
- [ ] Recreating an environment from the templates yields a working empty application.
- [ ] No secret is stored in the templates.

_Notes:_ NFR-008 (recreate from Bicep), NFR-022.

---

### S-12.01.03: Configure the App Service for transport and availability

**Estimated Hours:** TBD

As a Software Engineer, I want HTTPS-only transport and Always On so that the site is encrypted and the sweeper is not unloaded.

_Acceptance criteria:_

- [ ] HTTP is redirected to HTTPS, TLS 1.2 is the minimum and HSTS is set.
- [ ] Always On is enabled so the in-process sweeper keeps running.
- [ ] Secrets are App Service settings or Key Vault references.

_Notes:_ NFR-011; ADR-0018 follow-up.

---

### S-12.01.04: Connect with managed identity and protect the key ring

**Estimated Hours:** TBD

As a Software Engineer, I want the application to reach Azure SQL with a managed identity so that no database password exists.

_Acceptance criteria:_

- [ ] The app connects with a managed identity that has a least-privilege database role; the SQL firewall is restricted.
- [ ] The data protection key ring is persisted (database or Key Vault) so restarts and redeployments do not invalidate cookies, with restricted access.
- [ ] The decision on key ring protection is recorded (SEC-10).

_Notes:_ SEC-10.
