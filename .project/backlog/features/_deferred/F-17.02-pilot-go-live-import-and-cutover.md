## Description

Executes the one-off cutover: decide the go-live date, add the real people, run the real import before opening time, work through rejected rows with Office Operations, retire the spreadsheet and disable the import page.

## Scope Detail

- Go-live date, trigger and owner decision
- Office Operations delivers the cleaned CSV export; admins add up to 50 real people and rooms are confirmed
- Real import run, report review, correction and re-import, settle and purge
- Spreadsheet retirement and import disabled by configuration

## Technical Approach

Runbook-driven cutover using the POC import module unchanged.

## Stories

---

### S-17.02.01: Decide the go-live date and prepare inputs

**Estimated Hours:** TBD

As a Program Manager, I want the go-live date and preparation tasks agreed so that the import window and the people list are ready.

_Acceptance criteria:_

- [ ] Go-live date, owner and a runbook are agreed; the import window is computed from the date.
- [ ] Office Operations delivers the cleaned CSV export and the real people are added by an admin with the gate assignment.
- [ ] Rooms are confirmed against the specification.

_Notes:_ ADR-0012; ADR-0001.

---

### S-17.02.02: Run the real import and resolve rejections

**Estimated Hours:** TBD

As a Software Engineer, I want the real import run before opening time so that the first week's bookings exist on day one.

_Acceptance criteria:_

- [ ] The import runs before 08:00 on the go-live day, and every rejected row is reviewed with Office Operations.
- [ ] Corrected rows are re-imported without duplicates and the import is settled so report rows are purged.
- [ ] Counts are recorded in the go-live log.

_Notes:_ E2E-013.

---

### S-17.02.03: Retire the spreadsheet and disable the import

**Estimated Hours:** TBD

As a Program Manager, I want the spreadsheet retired and the import disabled so that the tool becomes the single source of truth.

_Acceptance criteria:_

- [ ] The spreadsheet is retired and the announcement states the new way to book.
- [ ] The import page is disabled by configuration.
- [ ] The go-live log records who did what and when.

_Notes:_ IM-10; project context (spreadsheet retired after the one-week import).
