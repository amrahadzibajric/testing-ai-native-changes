## Description

Switches the persistence provider to Azure SQL with a fresh baseline migration and SQL Server-appropriate types, keeping SQLite available for local development.

## Scope Detail

- Azure SQL baseline migration with `rowversion`, case-insensitive collation and `datetime2`/`date`
- Provider selection by configuration; managed identity connection
- Hosted seeding policy

## Technical Approach

Change only the persistence configuration point and generate a new migration set; do not carry SQLite migrations across.

## Stories

---

### S-13.01.01: Generate the Azure SQL baseline migration

**Estimated Hours:** TBD

As a Software Engineer, I want a SQL Server baseline migration so that the schema uses native types.

_Acceptance criteria:_

- [ ] The migration uses `rowversion`, a case-insensitive collation on email and room name, and `datetime2` and `date` for instants and dates.
- [ ] No SQLite-specific construct is carried over.
- [ ] The provider-neutrality guard from F-02.02 still passes.

_Notes:_ ADR-0025 follow-ups.

---

### S-13.01.02: Select the provider by configuration

**Estimated Hours:** TBD

As a Software Engineer, I want configuration to choose SQLite or Azure SQL so that local development and hosting share the code.

_Acceptance criteria:_

- [ ] A setting chooses the provider and connection; hosted uses the managed identity connection.
- [ ] Local development still runs on SQLite with `dotnet run`.
- [ ] Startup fails with a clear message if the chosen provider's configuration is incomplete.

_Notes:_ Persistence configuration point.

---

### S-13.01.03: Define hosted seeding and bootstrap behaviour

**Estimated Hours:** TBD

As a Software Engineer, I want no demonstration data in the hosted database so that real data is never mixed with synthetic data.

_Acceptance criteria:_

- [ ] Hosted environments run migrations and the bootstrap admin step but not the demonstration seed; rooms are created or seeded as agreed for the pilot.
- [ ] The bootstrap admin comes from hosted configuration with the same fail-fast behaviour.
- [ ] The demonstration seed toggle is off by default outside development.

_Notes:_ F-02.05, F-02.06.
