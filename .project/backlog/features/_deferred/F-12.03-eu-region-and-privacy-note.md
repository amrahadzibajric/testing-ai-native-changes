## Description

Delivers the simple privacy note for the names and emails stored and confirms EU data residency of the deployed resources.

## Scope Detail

- Privacy note text agreed with Office Operations
- Static privacy note page linked from the application
- Data policy confirmation and EU residency verification

## Technical Approach

A static Razor page with agreed text; verification by inspecting deployed resource locations.

## Stories

---

### S-12.03.01: Agree the privacy note text

**Estimated Hours:** TBD

As a Program Architect, I want the privacy note text agreed so that users know what is stored and why.

_Acceptance criteria:_

- [ ] The text states what is stored (name, email, role, booking history, audit records including the gate sign-in name, and transient import report rows), why, who can see it, how long (NFR-021) and whom to contact.
- [ ] Office Operations has approved the wording.
- [ ] The text reflects the purge of import report rows.

_Notes:_ ADR-0015 decision 2; data-model README Personal data.

---

### S-12.03.02: Publish the privacy note page

**Estimated Hours:** TBD

As a Software Engineer, I want a privacy note page linked from the application so that the note is easy to find.

_Acceptance criteria:_

- [ ] A static page renders the agreed text and is linked from the footer on every page.
- [ ] The page is reachable by any signed-in user and meets the accessibility baseline.
- [ ] Changing the text requires no code change beyond the page content.

_Notes:_ Arch component view PP (privacy note page).

---

### S-12.03.03: Confirm data policy and EU residency

**Estimated Hours:** TBD

As a Program Architect, I want the data policy confirmed and residency verified so that NFR-014 is closed.

_Acceptance criteria:_

- [ ] Any company data-protection policy covering names, emails and the audit sign-in name is identified or confirmed absent.
- [ ] All deployed resources are verified to be in the chosen EU region.
- [ ] The log and telemetry retention period is agreed.

_Notes:_ NFR-014.
