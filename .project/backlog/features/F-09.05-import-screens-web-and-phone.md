## Description

The screens an admin uses for the import: enter the go-live date, upload the file, read the result summary and the rejected rows, and handle an unreadable file.

## Scope Detail

- Upload form with go-live date and file, showing the computed window
- Result summary with imported, duplicate and rejected counts
- Rejected rows table with reasons; unreadable header and disabled-import states
- Phone version

## Technical Approach

Razor Pages built on F-03 components; result rendered from the ImportRun and report rows; loading state for processing.

## Stories

---

### S-09.05.01: Build the upload and result summary

**Estimated Hours:** TBD

As a Software Engineer, I want an upload screen with a clear result summary so that an admin sees what happened at a glance.

_Acceptance criteria:_

- [ ] The screen follows S03-import: go-live date, file chooser, the computed five-working-day window, and a loading state during processing.
- [ ] After processing it shows counts for imported, duplicate and rejected rows and that they add up to the total.
- [ ] A fully successful import shows a success state with no rejected rows.

_Notes:_ E2E-013 steps 1 to 3.

---

### S-09.05.02: Build the rejected-rows table and refusal states

**Estimated Hours:** TBD

As a Software Engineer, I want the rejected rows and refusal states shown clearly so that the admin knows exactly what to fix.

_Acceptance criteria:_

- [ ] The table lists line number, the six values and every reason by name; long tables scroll and the download and settle actions are available.
- [ ] An unreadable header, wrong encoding or over-cap file shows the whole-file refusal state with the reason.
- [ ] When import is disabled by configuration the page explains this and offers no upload.

_Notes:_ S03-states; NFR-017.

---

### S-09.05.03: Build the phone import screen

**Estimated Hours:** TBD

As a Software Engineer, I want the import screen usable at phone width so that an admin can review a result from a phone.

_Acceptance criteria:_

- [ ] The phone layout follows S03-import-mobile: form, result summary and a list of rejected rows with reasons.
- [ ] Touch targets are at least 44 px and the screen is reached from the Admin tab hub.
- [ ] Accessibility baseline applies.

_Notes:_ NFR-016.
