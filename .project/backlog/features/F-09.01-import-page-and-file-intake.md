## Description

Delivers the admin-only import entry point: choose a go-live date and upload a CSV. The whole file is checked before any row is read, and an unacceptable file is refused entirely with a clear message.

## Scope Detail

- Admin-only import page with go-live date and file upload; can be disabled by configuration
- Whole-file checks: UTF-8, header row with the six columns, size cap, row cap
- CSV parsing with values captured exactly as supplied and line numbers
- The raw file is never persisted

## Technical Approach

Streaming CSV reader with strict quoting rules; the file is processed in memory and discarded; an ImportRun with outcome FileRefused is recorded for refusals.

## Stories

---

### S-09.01.01: Provide the admin-only import entry point

**Estimated Hours:** TBD

As a Software Engineer, I want an admin-only import page with a go-live date and a file field so that an admin can start the one-off import.

_Acceptance criteria:_

- [ ] Only admins can open the page and upload; employees are refused.
- [ ] The admin enters the go-live date and chooses a CSV file.
- [ ] When import is disabled by configuration the page and navigation entry are unavailable and a direct request is refused.

_Notes:_ IM-10, IM-11; E2E-013 step 1.

---

### S-09.01.02: Refuse an unacceptable file as a whole

**Estimated Hours:** TBD

As a Software Engineer, I want whole-file checks so that a wrong or dangerous file writes nothing.

_Acceptance criteria:_

- [ ] A file that is not valid UTF-8, has no header row, lacks any of the columns `room`, `person_email`, `date`, `start`, `end`, `attendees`, exceeds the size cap or exceeds the row cap is refused with a message naming the reason.
- [ ] No booking is written; an ImportRun with outcome FileRefused and the reason is recorded and ImportFileRefused is audited.
- [ ] An unreadable header shows the refusal state from the design.

_Notes:_ SEC-08; E2E-013 failure path (wrong header); data-model ImportRun.

---

### S-09.01.03: Parse rows exactly as supplied

**Estimated Hours:** TBD

As a Software Engineer, I want a strict CSV reader so that each row's values are captured exactly as given and nothing is silently corrected.

_Acceptance criteria:_

- [ ] Quoted values, embedded commas and quotes are read correctly and every data row gets a line number (header is line 1).
- [ ] Values are kept as supplied, including their whitespace and case, so the report can show them unchanged; a value with stray whitespace fails format validation rather than being trimmed.
- [ ] Blank lines are skipped and counted consistently with line numbers.

_Notes:_ IM-06 (no silent changes).

---

### S-09.01.04: Never persist the raw file

**Estimated Hours:** TBD

As a Software Engineer, I want the uploaded file discarded after processing so that personal data in the file is not retained.

_Acceptance criteria:_

- [ ] The raw file is not written to disk or the database; only file name, size and outcome are kept on the ImportRun.
- [ ] The file name is treated as untrusted text and escaped wherever displayed.
- [ ] No row values are written to logs.

_Notes:_ Integration assessment gap 9; SEC-06, SEC-09.
