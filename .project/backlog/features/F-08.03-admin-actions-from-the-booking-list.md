## Description

From any booking in the admin list, an admin can cancel it or open it for editing, using the lifecycle features rather than a separate implementation.

## Scope Detail

- Cancel from the list (origin AdminCancelled unless the admin owns the booking)
- Open for edit from the list
- Confirmation, refresh and refusal handling

## Technical Approach

Row actions invoke the lifecycle service (F-07.01, F-07.02) with the admin as acting person.

## Stories

---

### S-08.03.01: Cancel a booking from the list

**Estimated Hours:** TBD

As a Software Engineer, I want a cancel action on each booking in the admin list so that admins can free rooms quickly.

_Acceptance criteria:_

- [ ] An admin can cancel a Confirmed booking that has not started; it is recorded with origin AdminCancelled and never late-flagged.
- [ ] Started, done, no-show and already cancelled bookings do not offer cancel and are refused if attempted.
- [ ] The list refreshes and the owner sees "Cancelled by admin".

_Notes:_ E2E-009 step 3, step 4.

---

### S-08.03.02: Open a booking for editing from the list

**Estimated Hours:** TBD

As a Software Engineer, I want an edit action on each editable booking so that admins can correct bookings for people.

_Acceptance criteria:_

- [ ] The action opens the edit drawer or sheet from F-07.01 for a Confirmed booking that has not started.
- [ ] All booking rules are re-run and refusals name the rule.
- [ ] The audit event records the admin as the acting person with the admin flag.

_Notes:_ M-05 capability 5.

---

### S-08.03.03: Confirm destructive actions and refresh the list

**Estimated Hours:** TBD

As a Software Engineer, I want confirmations and a refreshed list so that admin mistakes are less likely and outcomes are clear.

_Acceptance criteria:_

- [ ] Cancel uses the confirm modal (web) or sheet (phone) naming the person, room and time.
- [ ] After success the row shows its new status without a full page reload confusion, with a success toast.
- [ ] A refusal (for example the booking started meanwhile) shows the named reason and leaves the list intact.

_Notes:_ Uses F-03.02 surfaces and feedback patterns.
