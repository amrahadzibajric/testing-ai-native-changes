## Description

Implements the approved style contract as CSS design tokens and base styles so all pages share one visual language.

## Scope Detail

- Colour tokens at 60/30/10: warm neutral background, graphite structure, single signal-orange accent, semantic status colours
- Radius, spacing, elevation and motion tokens from the style contract
- Inter Tight and Inter with tabular figures, 1.2 scale, self-hosted
- Focus ring, selection colour, thin scrollbars, antialiasing; light mode only

## Technical Approach

CSS custom properties in a single stylesheet layer consumed by Razor layout and partials. Fonts served from the application, not a CDN.

## Stories

---

### S-03.01.01: Implement colour, radius, spacing, elevation and motion tokens

**Estimated Hours:** TBD

As a Software Engineer, I want the style-contract tokens as CSS variables so that every component uses the same values.

_Acceptance criteria:_

- [ ] Tokens exist for off-white background `#F7F6F3`, graphite text `#1F2328`, muted `#5B616B`, border `#E3E1DC`, accent `#C2410C`, and the semantic status colours.
- [ ] Radius (6, 8, 12, 999 px), spacing (4 px base), the elevation set and the 140 to 180 ms motion set match `design-direction.md`.
- [ ] Only one accent colour exists; it is used only for the primary action, the selected slot and the live "now" line, and meets AA contrast on white.

_Notes:_ Design direction, Style Contract starting values.

---

### S-03.01.02: Implement typography with self-hosted fonts

**Estimated Hours:** TBD

As a Software Engineer, I want Inter Tight and Inter with tabular figures self-hosted so that times and counts align and the demonstration works without internet.

_Acceptance criteria:_

- [ ] Inter Tight (600 to 700) is used for page titles and the date header; Inter (400 to 600) for all other text, on a 1.2 scale.
- [ ] Tabular numerals apply wherever a time or count appears so 09:15 and 10:45 align.
- [ ] With the network disabled, the pages still render with the intended fonts.

_Notes:_ The POC is demonstrated locally, possibly without connectivity.

---

### S-03.01.03: Implement base detail

**Estimated Hours:** TBD

As a Software Engineer, I want the base interaction detail so that every control feels consistent and accessible.

_Acceptance criteria:_

- [ ] Every interactive element shows the focus ring `0 0 0 3px rgba(194,65,12,.35)` on keyboard focus.
- [ ] Text selection uses the orange tint; timeline containers use thin custom scrollbars; text is antialiased.
- [ ] Light mode only; no dark-mode styles exist.

_Notes:_ Design direction, Detail row.
