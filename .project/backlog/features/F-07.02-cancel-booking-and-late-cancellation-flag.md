## Description

Lets owners cancel their own bookings and admins cancel anyone's, before the booking starts, with the late-cancellation flag set only when the owner cancels less than 2 hours before start.

## Scope Detail

- Owner cancellation with origin OwnerCancelled
- Late flag set once, only by the owner, less than 2 hours before start
- Admin cancellation of another person's booking with origin AdminCancelled, never late
- Refusals for started or finished bookings
- Confirm dialog with late warning; audit with origin

## Technical Approach

Lifecycle service using the office clock and the cancellation origin field; late flag computed at cancellation time and never changed afterwards.

## Stories

---

### S-07.02.01: Cancel my own booking

**Estimated Hours:** TBD

As a Software Engineer, I want the owner to cancel a booking that has not started so that unneeded rooms are released.

_Acceptance criteria:_

- [ ] The owner can cancel a Confirmed booking that has not started; it becomes Cancelled with origin OwnerCancelled and the room is free for that time.
- [ ] The person's upcoming count drops by 1.
- [ ] An employee cannot cancel another person's booking.

_Notes:_ LC-05; E2E-003 step 3.

---

### S-07.02.02: Flag late cancellations

**Estimated Hours:** TBD

As a Software Engineer, I want the owner's cancellation less than 2 hours before start flagged so that admins can see who cancels late.

_Acceptance criteria:_

- [ ] Cancelling 2.5 hours before start is not flagged; cancelling 1.5 hours before start is flagged as a late cancellation; exactly 2 hours before start is not flagged.
- [ ] The flag is set once at cancellation and never changes afterwards, and no edit ever sets it.
- [ ] An admin cancelling their own booking is recorded as OwnerCancelled and can be late-flagged.

_Notes:_ LC-06; AO-03; E2E-007 steps 1 to 3; data-model decision accepted 2026-09-29.

---

### S-07.02.03: Cancel another person's booking as an admin

**Estimated Hours:** TBD

As a Software Engineer, I want admins to cancel anyone's booking so that admins can help people and manage rooms.

_Acceptance criteria:_

- [ ] An admin cancelling another person's booking sets origin AdminCancelled and records the admin as the canceller.
- [ ] The cancellation is never late-flagged, even less than 2 hours before start.
- [ ] The owner sees the booking as "Cancelled by admin", not as their own cancellation.

_Notes:_ ADR-0015 decision 3; E2E-009 steps 3 and 4.

---

### S-07.02.04: Refuse cancellation once started or finished

**Estimated Hours:** TBD

As a Software Engineer, I want cancellation refused after the start so that started meetings cannot be removed.

_Acceptance criteria:_

- [ ] Cancelling a booking that has started (checked in or not), is done, no-show or already cancelled is refused with a message stating the reason.
- [ ] The booking is unchanged after a refusal.
- [ ] The same rule applies to admins.

_Notes:_ LC-13; ADR-0014 rule 1; E2E-008 steps 2 and 3.

---

### S-07.02.05: Build the cancel interactions and audit

**Estimated Hours:** TBD

As a Software Engineer, I want a clear cancel confirmation and an audit record so that late cancellations are understood and traceable.

_Acceptance criteria:_

- [ ] The confirm step warns "this will be recorded as a late cancellation" when the cancellation would be late, and does not when it would not.
- [ ] BookingCancelled is audited with the cancellation origin and late flag.
- [ ] The interaction works on web and phone and meets the accessibility baseline.

_Notes:_ S02-states; NFR-020.
