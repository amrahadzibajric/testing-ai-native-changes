## Description

Records everything deferred by ADR-0024 with its trigger and prerequisites, the checklist for the SQLite to Azure SQL switch, and a way to capture client feedback from the demonstration and route it correctly.

## Scope Detail

- Register of deferred items mapped to E-12 to E-17
- Switch checklist and the tests to re-run on SQL Server
- Feedback capture and routing (ADR, intake or feature file update)

## Technical Approach

A markdown register and a feedback template kept with the run documentation.

## Stories

---

### S-11.03.01: Create the deferred-items register and switch checklist

**Estimated Hours:** TBD

As a Program Architect, I want a register of every deferred item so that nothing parked by ADR-0024 is forgotten.

_Acceptance criteria:_

- [ ] The register lists Azure hosting, EU region and privacy note, tenant access gate, Azure DevOps CI/CD, Entra ID sign-in path, Application Insights, managed identity, Bicep and hosted performance and security testing, each with its ADR, the backlog EPIC and the trigger.
- [ ] The switch checklist covers the Azure SQL baseline migration, `rowversion`, collation, the UPDLOCK per-room lock and re-running the concurrency, collation and audit tests on SQL Server.
- [ ] It states that the security assessment must be re-run against the hosted design before any hosted deployment, and that owner and date for the post-POC phase are still to be assigned.

_Notes:_ ADR-0024 follow-ups; ADR-0025 follow-ups.

### S-11.03.02: Capture demonstration feedback and route changes

**Estimated Hours:** TBD

As a Program Architect, I want a feedback template with routing rules so that client comments become tracked changes.

_Acceptance criteria:_

- [ ] The template records each comment, who raised it, the affected module and whether it is a rule confirmation, a scope change or a defect.
- [ ] Routing follows the change-management rules: scope-material decisions become an ADR, new stakeholder requirements an intake record, feature-level tweaks a feature file update.
- [ ] Answers to the ADR-0011 to ADR-0015 confirmations are transcribed into the outcome log from S-01.02.01.
